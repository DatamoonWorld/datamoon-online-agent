# Regras Especializadas

Esta pasta orienta Devmoon ao implementar. Ela nao guarda roadmap, comandos de
VM ou fichas de especies.

- `CODE_RULES.md`: regras comuns de ownership, implementacao, refatoracao,
  performance e validacao.
- `SERVER_ARCHITECTURE.md`: fronteiras e fluxos entre Client, Auth, Gateway,
  Game Server, MySQL API e Web.
- `DATABASE_RULES.md`: modelagem, transacoes, ownership, idempotencia,
  migrations e auditoria.
- `NETWORK_RULES.md`: mensagens, autoridade, ordenacao, rate limit, prediction,
  snapshots e handoff.
- `GODOT_STANDARDS.md`: convencoes de cenas, scripts, nodes, signals, recursos e
  performance em Godot.
- `DATAMOON_CREATION_RULES.md`: criterio criativo para conceito, tipo, visual,
  lore, combate e evolucao de Datamoons.

Quando duas regras parecerem competir, `../AGENTS.md` define o proprietario e o
documento mais especializado define os detalhes.
