# Datamoon Online Agent

Repositorio oficial de conhecimento e operacao de Datamoons Online.

Ele nao contem o runtime do jogo. Sua funcao e manter alinhados Devmoon, regras
de engenharia, lore, sistemas, roadmap e operacao da VM.

## Navegacao

- `AGENTS.md`: identidade e regras obrigatorias de Devmoon;
- `docs/README.md`: indice de toda documentacao;
- `docs/GAMEPLAY_FEATURES.md`: escopo editavel das funcionalidades;
- `docs/FIRST_BETA_ROADMAP.md`: trabalho atual e release gates;
- `docs/OPERATIONS.md`: runbook da VM;
- `ai/README.md`: indice das regras especializadas de implementacao;
- `ops/README.md`: inventario dos arquivos instalados ou executados na VM;
- `docs/species/`: fichas autorais de cada Datamoon.

Cada informacao possui um unico proprietario. Status vive no roadmap; desenho
funcional em `GAMEPLAY_FEATURES.md`; detalhes no documento tematico; historico
transversal no Decision Log.
